# 프로젝트 이미지 폴더 안내

이 폴더에 각 프로젝트의 실제 이미지를 넣어주시면 됩니다.

### 파일명 규칙:
1. `project-01.png` - 프로젝트 1번 (사내 업무 서식 표준화)
2. `project-02.png` - 프로젝트 2번 (월간 사내 소통 뉴스레터 & 카드뉴스)
3. `project-03.png` - 프로젝트 3번 (부서 비전 워크숍 행사 키트)
4. `project-04.png` - 프로젝트 4번 (반응형 사내 정보 게시판 UI)
5. `project-05.png` - 프로젝트 5번 (경영 지원 월간 실적 보고서)

### 이미지 적용 방법:
이미지를 이 폴더에 넣은 후, `src/data/portfolioData.js` 파일에서 해당 프로젝트의 `isImageReady: false`를 `isImageReady: true`로 변경하시면 실제 이미지가 바로 화면에 렌더링됩니다!
